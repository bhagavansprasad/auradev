Reduce the video file size by 40%
    ffmpeg -i original.mp4 -crf 40 new.mp4


Reduce the video file size by 50% (Un-watchable)
    ffmpeg -i original.mp4 -crf 50 new.mp4


Merge mp4 files
	Contents of inputs.txt
		file 'a.mp4'
		file 'b.mp4'

	ffmpeg -f concat -safe 0 -i inputs.txt -c copy output.mp4

Increase the volume of the audio by 10 levels
	ffmpeg -i 05-Subgraph.mp4 -af "volume=+20dB" -c:v copy new/05-Subgraph.mp4
	ffmpeg -i 05-Subgraph.mp4 -af "volume=10.0" -c:v copy new/05-Subgraph.mp4
	ffmpeg -i 05-Subgraph.mp4 -af loudnorm -c:v copy new/05-Subgraph.mp4
